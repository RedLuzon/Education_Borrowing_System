# 📚 Education Borrowing System (Orange Edition)

A smart, modern resource lending and inventory portal built with **Java Swing**. Designed for educational institutions to efficiently manage equipment, laboratory apparatus, math tools, textbooks, and technology gear with a clean, flicker-free UI.

---

## ✨ Key Features

- **Role-Based Access Control (RBAC)**: Secure authentication supporting distinct privileges for **Super Admin** and **Staff/Librarians**.
- **Modern Flat UI / Custom Kit**: Custom-crafted Java Swing components featuring smooth card navigation (`CardLayout`), rounded panels, gradient backgrounds, and responsive layouts.
- **Inventory & Catalog Management**: Real-time tracking of various educational assets across categories like Equipment, Science, Math, Books, and Technology.
- **Check-Out & Return Workflow**: Seamless transaction processing for borrowing and returning school resources.
- **Activity Logging & StatusBar**: Live timestamp monitoring and system activity logging to maintain a secure audit trail.
- **Flicker-Free Rendering**: Optimized rendering pipelines using double buffering and clean event management to eliminate UI flashing during interactions.

## 🛠️ Tech Stack

- **Language**: Java (JDK 8 or higher)
- **Framework**: Java Swing (AWT, Swing Utilities, Custom Look & Feel)
- **Architecture**: Modular Controller-View Pattern (`BorrowingSystem.java` as central entry point)
- **IDE**: IntelliJ IDEA
